How to use the overlay

1. Enter a Twitch channel name above and click Save

2. Press and hold Alt+Backspace to interact with the overlay

3. When Alt is held, drag the top purple bar to move

4. When Alt is held, drag the bottom-right corner to resize

5. Release Alt to make the overlay click-through
